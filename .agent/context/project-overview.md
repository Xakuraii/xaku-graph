# XakuGraph Project Context

XakuGraph is an open-source Data & AI Visualization Studio.

## Target Audience
- Software developers
- AI/ML researchers and students
- Data scientists
- RAG pipeline practitioners

## Planned Core Modules
1. Dataset Visualization (Ingestion, statistics, distributions, preview)
2. Embedding Visualization (Model adapters, PCA/t-SNE/UMAP, 2D/3D inspection)
3. Vector & Similarity Explorer (Mathematical similarity in high dimensions)
4. RAG Visualization (Read-only connectors, chunking inspection, retrieval)
5. ML Visualization (Loss metrics, confusion matrices, feature importance)
