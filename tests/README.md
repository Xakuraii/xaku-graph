# XakuGraph Test Suites

This directory contains integration and end-to-end test suites.

## Directory Structure
- `integration/`: Cross-layer tests verifying backend API with real fixtures.
- `e2e/`: End-to-end browser and desktop lifecycle tests.
- `fixtures/`: Small, non-sensitive datasets and test vectors.

## Running Tests
Run the project-wide test runner:
```powershell
./scripts/test.ps1
```
